# RN Login App

React Native (TypeScript) app with a Login screen, client-side validation, mocked auth API, and Jest + Testing Library coverage.

## Scripts

- `yarn test` — run Jest unit/UI tests
- `yarn typecheck` — TypeScript check (`tsc --noEmit`)

## Stack

- React Native + TypeScript
- Jest + `@testing-library/react-native`
- Mocked `login` API (no network)

Frontend only — no Detox, Playwright, or emulator required for tests.
